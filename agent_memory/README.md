# Agent Memory

Tracked durable memory for this skill-development repo.

Use this folder for decisions and rejected/deferred ideas that should survive branch deletion, rollbacks, and ignored `progress_logs/` churn.

Use `progress_logs/` only for supplementary exploratory or integration context. GitHub Issues is the authoritative work queue; promote durable knowledge here.

Current files:

- `tracker.md` — authoritative work-tracker contract and artifact boundaries.
- `key_decisions.md` — durable architectural decisions.
- `deferred_ideas.md` — postponed or rejected ideas that should remain visible.
- `fanout_extraction_spec.md` — implementation and A/B testing spec for `read-pdf` / `wiki-update` fanout extraction.
