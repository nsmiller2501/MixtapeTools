# /writing-great-skills

Reference for writing and editing agent skills well: invocation, information hierarchy, progressive disclosure, leading words, and pruning failure modes.

Useful when creating a new skill, deciding whether an upstream skill earns its place, or auditing an existing skill for excess machinery.
